## 🏛️ Descripción General

Ecosistema web interactivo desarrollado en **React 18 + Vite** con arquitectura desacoplada, renderizado condicional de alto rendimiento y metamorfosis dinámica entre tres lentes técnicos de evaluación:

1. **👔 Modo CTO & Arquitectura SaaS:** Enfoque ejecutivo en modelado de dominio, diagramación C4, Clean Architecture y métricas pragmáticas de negocio (CAR).
2. **💻 Modo Consola Cyber & Low-Level:** Terminal interactiva estilo CLI con comandos en vivo (`help`, `audit motoe6s`, `clear`), telemetría de kernel y criptoanálisis de hardware.
3. **✨ Modo Creative UI & WebGL 3D:** Entorno visual con aceleración gráfica, simulación de partículas reactivas y rig 2.5D de avatar interactivo.

---

## 🛠️ Tecnologías & Principios de Diseño

* **Core Frontend:** React 18, React Router 6, Vite, Context API.
* **Estilos & Animaciones:** Vanilla CSS modular, Container Queries, Framer Motion, Confetti Canvas.
* **Rendimiento:** Cero dependencias pesadas innecesarias, lazy loading de componentes 3D, tiempo de carga inicial ultrarrápido.
* **Metodología:** Relevamiento $\rightarrow$ Modelado de Dominio $\rightarrow$ Clean Architecture $\rightarrow$ Trazabilidad & Despliegue.

## 🚀 Despliegue & Ejecución Local

### Requisitos Previos
* Node.js 18+ y npm instalados.

### Instalación y Ejecución
```bash
# 1. Clonar el repositorio
git clone https://github.com/Augustoromera/PortafolioAugusto2023Frontend.git

# 2. Acceder al directorio
cd PortafolioAugusto2023Frontend

# 3. Instalar dependencias
npm install

# 4. Iniciar servidor de desarrollo
npm run dev

# 5. Generar paquete de producción
npm run build
```
